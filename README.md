# 人教版数学 · 章节同步教练

以**人教版数学教材章节**为内容主轴的学习项目。内容按「学段 → 年级/册 → 分册（上/下）→ 章」循序组织；每个章节挂载**配套学习方法**（与主线进度对应），并贯穿三类**学习技巧**——知识梳理、错题复盘、间隔巩固，形成「学一章、理一章、练一章、错一题复盘一题、按遗忘曲线反复提取」的闭环。

纯前端、离线可用、零依赖、零后端；数据全部持久化于浏览器 `localStorage`。

---

## 一、整体架构

系统采用**三层解耦**结构，数据驱动、模块可独立替换：

```
┌──────────────────────────────────────────────────────────┐
│  表现层 (app.js + styles.css + index.html)                 │
│  路由 / 页面渲染 / 交互 / 顶部导航与徽标                    │
├──────────────────────────────────────────────────────────┤
│  引擎层 (techniques.js + methods.js + figures.js)          │
│  学习技巧引擎：知识梳理·错题复盘·间隔巩固(Leitner)          │
│  学习方法库：8 类学法的定义与学段映射                       │
│  配图引擎：数轴/韦恩图/点阵等 SVG                          │
├──────────────────────────────────────────────────────────┤
│  数据层 (data.js)                                          │
│  人教版全学段章节骨架 + 示范章完整内容 + 解锁规则           │
└──────────────────────────────────────────────────────────┘
                         │
                   localStorage（state 持久化）
```

| 层 | 文件 | 职责 | 可替换性 |
|----|------|------|----------|
| 数据层 | `js/data.js` | 章节树、每章 methods/knowledge/questions、年级内顺序解锁规则 | 换教材只需改此文件 |
| 引擎层 | `js/techniques.js` | 知识卡渲染、错题捕获、Leitner 间隔调度 | 技巧算法独立，不依赖页面 |
| 引擎层 | `js/methods.js` | 8 类学习方法定义 + 学段→方法映射 | 扩充学法只改此文件 |
| 引擎层 | `js/figures.js` | SVG 配图（数轴/韦恩/点阵/对比） | 纯展示，可接图片资源 |
| 表现层 | `js/app.js` | hash 路由、状态、各页面组装 | 视图与交互 |

## 三、章节与模块对应关系

**主轴**：教材章节是唯一组织轴。每个章节对象挂载四类内容，分别驱动不同模块：

```
章节 Chapter
 ├─ methods[]      → 学习页「本阶段配套学习方法」+ 方法库映射
 ├─ knowledge[]    → 学习页「知识梳理卡 + 思维导图」+ 间隔复习(标记后)
 ├─ questions[]    → 练习模块（答错→错题本）
 └─ built 状态     → 未填充章显示「内容建设中」，但主线可达
```

**学段 → 学习方法 对应关系**（学法随主线进度进阶）：

| 学段 | 配套学习方法 | 设计意图 |
|------|--------------|----------|
| 小学 | 预习四步法 · 精读圈画法 · 错题复盘法 · 间隔巩固法 | 建立基础习惯，重直觉与规范 |
| 初中 | 预习 · 精读 · **归纳总结法** · **易混对比法** · 错题复盘 · 间隔巩固 | 概念变多，重在体系化与辨析 |
| 高中 | 精读 · 归纳 · 对比 · **解题五步法** · **费曼输出法** · 错题复盘 · 间隔巩固 | 抽象综合，重套路与输出验证 |

> 错题复盘、间隔巩固为**跨学段贯穿技巧**，在每个章节都生效，不随学段增减。

**示范章**（已完整填充，覆盖三学段起点）：

## 四、学习技巧在系统中的嵌入方式

三类技巧以「**数据层记录 + 引擎层调度 + UI 层入口 + 行为触发**」四重方式嵌入，而非孤立功能：

### 1. 知识梳理（Knowledge Organization）
- **数据层**：每章 `knowledge[]` 存结构化卡片（term/def/tip）。
- **UI 层**：学习页渲染知识卡 + 自动生成的思维导图（`techniques.buildMindmap`）。
- **触发**：点击「我已梳理本章知识」→ 写入 `state.knowledgeDone[chId]` 并 `ensureReview("k:"+chId)`，本章知识卡即进入间隔复习队列。

### 2. 错题复盘（Mistake Review）
- **数据层**：`state.mistakes[]` 记录原题、错答、正解、错因标签、三问。
- **引擎层**：练习答错时 `TECH.captureMistake()` 去重入库并 `ensureReview("m:"+id)`。
- **UI 层**：错题本页做错因归类 + 三问复盘；复习页做「重做」提取。
- **触发**：**练习答错即自动触发**，无需手动登记；顶部「错题复盘」徽标显示未清零数。

### 3. 间隔巩固（Spaced Reinforcement）
- **引擎层**：Leitner 五盒，`promote(key, ok)` 按 1/2/4/7/15 天节奏升级或回盒；满盒标记毕业。
- **统一调度**：错题（`m:`）与知识卡（`k:`）共用一套 `state.review` 调度器，`dueItems()` 合并产出「今日复习」队列。
- **UI 层**：间隔复习页只显示今日到期条目，负担最小；顶部「间隔复习」徽标显示到期数。
- **触发**：错题入册、知识卡标记即自动排程；做对升级、做错回盒。

```
学习闭环：
  学(学习页/学法) → 理(知识卡→排程) → 练(练习) → 错(自动入错题本)
       ↑                                                      ↓
  复习(间隔队列: 知识卡+错题, Leitner 调度) ←————— 复盘(三问/错因)
```

## 七、扩展指引（填充更多章节）

1. **加章节**：在 `data.js` 的 `PEP_SKELETON` 对应位置加入真实章节标题即可（骨架自动展开）；完整填充则在 `BUILT` 中以章节 `id` 为键补充 `summary/methods/knowledge/questions`。
2. **章节 id 规则**：`学段码 + 年级码 + 分册码 + "c" + 章序号`，如 `c7sc1`=初中·七上·第1章。
3. **加学法**：在 `methods.js` 的 `METHODS` 增一项，并在 `STAGE_METHOD_MAP` 的学段数组加入其 id。
4. **加参数化题**：题目中用 `gen: () => ({q, options, ans, explain})`，每次调用随机生成，天然支持「每遍不重样」。
5. **换科目/教材**：仅需替换 `data.js` 的章节树与内容，引擎层与表现层零改动。

## 九、长页面体验优化 & 错题卷「打印—扫码—重入库」闭环

### 1. 返回顶部悬浮按钮
- 固定在窗口右下角（`#toTop`），向下滚动超过约一屏（>320px）自动淡入，点击平滑回到顶部。
- 独立于 `#view` 之外，页面路由重渲染不会影响它；移动端同样可用。

### 2. 错题本一键打印（带核对二维码，打印即清空）
在「错题本」页点击 **🖨️ 打印错题卷** 后：

1. 弹出确认（避免误触导致数据丢失）→ 生成实体卷子并调用打印。
2. 卷子内容：**全部错题**（题号 + 归属章 + 题干 + 选项 + 作答横线 + 配图），**只印题目不印答案**，供孩子重做。
3. 卷尾「家长核对区」：每批一个**二维码**，二维码里装的是**正确答案 + 解析**。
4. 打印的同时，**当前错题库（未清零项）立即清空**（含其间隔复习排程）。

**二维码容量与自动分批**：单个二维码容量有限（v40-L 约 2953 字节）。系统先把错题编码为紧凑 JSON，再做 **LZW 压缩 + base64url**；若一整批装不下，则按「能装进单个二维码」自动切成多批（贪心填充，保证每批都可用），每批一个二维码，卷子正文仍是全部题目，家长逐批扫码即可。示例：50 道中等长度错题约自动分成 2 批。

### 3. 家长扫码 → 勾选错题 → 重新入库
- 家长用手机扫描卷尾二维码（`http://<部署地址>/#/scan?d=<编码数据>`）进入**核对页**。
- 页面逐题展示题干、选项、**正确答案与解析**，每题的「孩子又做错了」勾选框；支持「全选/取消」。
- 点击 **确认 · 重新加入错题库**，被勾选的题即通过 `TECH.captureMistake` 重新写入 `state.mistakes`，回到错题本与间隔复习队列。

```
打印错题卷 ──▶ 清空错题库 ──▶ 孩子纸上重做
     │                              │
     └── 卷尾二维码(含答案/解析) ───▶ 家长扫码逐批核对
                                     └─▶ 勾选又做错的题 ─▶ 重新入库(错题本/间隔复习)
```

> 技术要点：`printscan.js` 负责编码/压缩/分批/二维码；`app.js` 的 `openPrintSheet()` 负责生成打印版式与清空；`buildPaperHtml()/buildScanHtml()` 为纯函数，便于复用与预览。打印仅显示 `#printArea`（`@media print`），并等待二维码图片就绪后再唤起打印，避免空白码。

### 1. 分类与编号：对齐《小学奥数举一反三》目录

- 题库即按「年级 → 第 X 周 → 专题名」组织，与教材一一对应；
- 数据集中在 `js/oly-syllabus.js`（`window.OLY_SYLLABUS`），记录 `{周次, 专题名, 原书起始页}`。

| 年级 | 第 1 周 | … | 第 40 周 |

| 一 | 数数有多少 | … | 鸡兔同笼 |
| 二 | 比比眼力 | … | 综合练习 |

### 2. 版权与来源说明（重要）

- **只收录教材的目录级信息**（周次与专题名）。专题名属公有领域的知识点命名，目录本身不含题目内容；本项目**不复制、不收录任何原书题目文本**。

### 3. 题型引擎与覆盖

- `js/olympiad.js` 内置 **121 个题型引擎**（`Oly.ENG`），通过 `Oly.MAP`（`年级 → 周次 → 引擎 id`）映射到 240 个教材专题；
- 其中 **236 个专题**有专属引擎，其余 4 个为「综合练习 / 杂题」类，标记为 `__mixed__`，按该年级全部引擎混合出题；
- 一个引擎可服务多个年级的同类专题（如“数数图形”同时用于一、二、三、四、五年级对应周次），避免重复实现。

### 4. 与主线共用同一套技巧闭环

- 奥数题的作答界面与章节练习同构（题干 + 四选项 + 即时解析）；
- **答错自动进错题本**：以合成章 id `oly:<年级号>:<专题id>`（如 `oly:3:g3w16`）记录，错题本、打印错题卷、扫码复核、间隔复习**全部复用**，无需额外逻辑；
- 错题本中显示为「奥数·三年级·第16周 植树问题」；「重做本题」会正确跳回对应专题练习。

### 5. 关键实现

| 位置 | 说明 |
|------|------|
| `js/oly-syllabus.js` | 教材专题骨架（240 项）：`window.OLY_SYLLABUS[年级] = [{w,t,p}]`，**须在 `olympiad.js` 之前加载** |
| `js/olympiad.js` | 题型引擎（`ENG`）+ 专题映射（`MAP`）+ 对外 API（`window.Oly`） |
| `Oly.topicsOf(grade)` | 返回该年级 40 个专题：`{week, id:"g3w16", name, page, engine, desc, hasGen}` |
| `Oly.makeItems(grade, topicId, n)` | 生成 n 道去重题（按题目文本指纹去重，每遍不重样）；`topicId` 为空或 `__mixed__` 时按年级混合 |
| `Oly.chapterById(id)` | 把合成章 id 解析为 `{stage:"奥数", grade, title:"三年级·第16周 植树问题"}` |
| `app.js → renderOly / renderOlyPractice / paintOly` | `#/oly` 首页（年级标签 + 40 周专题网格）、`#/oly/p/<年级号>[/<专题id>]` 综合/专题练习 |

> **扩展方式**：① 若某个教材专题还没有专用引擎，在 `olympiad.js` 的 `EXTRA` 里加一项 `{id, name, desc, gen}`（`gen()` 返回 `{q, options, ans, explain, point}`）；② 再在 `MAP` 里把该周次指向新引擎 id 即可，不必改动其它文件。
